# vettr

Agent-first review IDE built with Electron + TypeScript + React.

## Read these first

- [docs/PROJECT_BRIEF.md](docs/PROJECT_BRIEF.md) - concept, decisions, architecture, hard problems and build order. Read it for context before making design or implementation choices.
- [README.md](README.md) - layout, scripts and the MVP to-do list. Read it for the current state of progress towards the MVP.

## Keeping the docs up to date (critical)

The brief and the README are the source of truth, and it is critical that they stay current.

- **Decisions:** whenever a decision is made or changed (architecture, scope, behaviour, tooling), update `docs/PROJECT_BRIEF.md` in the same piece of work. Keep the README consistent with it.
- **Progress:** as work lands, tick items off in the README MVP to-do list. Add, reword or remove items when scope changes, and keep the milestone order meaningful.
- Do not leave the docs describing a design that no longer matches the code or the agreed decisions.
